# 🧠 논의 및 결정 사항

## 논의 1. 카드팩 확률의 단일 기준

### 논의 내용

- 서버에는 V2 확률 정책이 반영됐으나 게임 규칙 문서의 확정 상태와 표현이 일치하지 않음.

### 의견

**개발자 A**

- 등급별 카드팩 확률을 게임 규칙에 명확히 공개할 필요가 있음.

**개발자 B**

- 서버 정책 버전과 문서의 확률표를 함께 관리해야 이후 변경 이력을 추적할 수 있음.

### 최종 결정

> 현재 서버의 V2 확률표를 검토 기준으로 삼되, 출시 확정 전 게임 규칙 문서와 최종 합의한다.

### 결정 이유

- 코드와 문서가 서로 다른 확률을 설명하면 사용자 고지와 운영 검증이 불가능하기 때문.

---

## 논의 2. 카드 판매 단위

### 논의 내용

- 확정 게임 규칙은 보관함 5장 일괄 판매이나 리뷰 의견에는 낱장 판매 제안이 있어 서로 충돌함.

### 의견

**개발자 A**

- 낱장 판매 방식도 검토할 필요가 있음.

**개발자 B**

- DB 트랜잭션과 광고 소비 방식을 구현하기 전에 판매 단위를 먼저 확정해야 함.

### 최종 결정

> 이번 주 합의 전까지 판매 API 구현 결정을 보류한다.

### 결정 이유

- 판매 단위에 따라 API 요청값, 광고 횟수, 보상 계산과 DB 구조가 모두 달라지기 때문.
