# 카드 가치 설정

`card-values.json`은 교환소 UI에서 직접 읽습니다.

- `grades.*.baseCrystals`: 등급별 1강 기본 결정 가치
- 카드 가치 = `baseCrystals × 강화 단계` (1~10강)
- `crystalsPerPoint`: 1포인트에 필요한 결정. 현재 서버 규칙과 같은 10000입니다.
- `enhancement`: 지원 강화 범위. 현재 UI와 게임 규칙은 1~10강을 전제로 합니다.

예: `NORMAL.baseCrystals`를 15000으로 바꾸면 노말 1강은 15000결정, 10강은 150000결정으로 표시됩니다.
금액은 양의 정수로 입력하세요. 변경 후 개발 화면을 새로고침하거나 앱을 다시 빌드해야 반영됩니다.

현재 교환소는 예시 카드로 금액을 계산하는 UI입니다. 실제 카드 판매, 잔액 차감, 토스 포인트 지급은 하지 않습니다.
이 파일은 현재 클라이언트 UI 설정입니다. 서버의 실제 지급 정책(`apps/server/src/cards/game-rules-v2.ts`)은 별도이므로 운영 금액 변경 시 함께 맞춰야 합니다.
